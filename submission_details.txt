IMPROVEMENTS TO BASE MODEL:

Architecture Changes:
- Increased filter sizes: 32→64→128 (base) to 64→128→256 (improved)
- Same depth (3 conv layers) for stability
- Wider filters allow learning more features per layer

Training Policy:
- Extended training from 45 to 80 epochs
- Learning rate decay at epochs 25, 50, 75 (step_size=25)
- Same initial LR=0.1, gamma=0.1

Results:
- Base model validation accuracy: 61.75%
- Improved model validation accuracy: 64.77%
- Total improvement: 3.02%

The wider filters provide more model capacity, and extended
training with multiple LR decays allows better convergence.
